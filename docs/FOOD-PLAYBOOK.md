# 美食 KV 生产规则 v0.1

本文件是拟实现的生产合同。当前没有真实图片、模型接入或通过质检的母版。

[主规格](../Product-Spec.md)定义总规则；本手册负责细化，不降低其事实、主体与验收要求。

## 1. 先识别食物，再决定设计

识别维度：`category / subcategory / preparation / temperature_cue / texture_cues / serving_context / cultural_context / positioning / audience / campaign_goal`。烹饪方法、食材配方和品牌属性不能仅凭视觉下结论；可见观察、用户提供与设计推测分栏记录。

| 品类示例 | 优先呈现的感官属性 | 可探索的光色、背景与排版 | 必须避免 |
|---|---|---|---|
| 面食、米饭、地方小吃 | 面体走向、湿润度、油光、酱汁关系 | 有方向的柔光、材质背景、亲切有力的标题 | 加粗面条、改成另一种面、擅加浇头、统一黑金国潮 |
| 烘焙、面包、糕点 | 开口、表皮、层次、烤色、整齐或手作特征 | 自然侧光、烘焙材质、编辑式构图、适合品牌的衬线或无衬线 | 擅造剖面、增加层数、改变切口、给橱窗面包套中餐牌匾 |
| 火锅、炖煮、热汤 | 原有汤色、食材位置、热度线索 | 温暖局部光、稳定器皿、聚拢型空间 | 凭空沸腾或飞溅、增加肉量、改变锅型 |
| 烤肉、煎炸 | 表皮焦痕、脆皮、油脂高光 | 克制硬光、深浅反差、结实字形、少量动势 | 过度焦黑、胶质塑料光、改变熟度 |
| 海鲜、刺身 | 生熟状态、肉质纹理、切片厚度 | 清洁背景、细腻高光、冷暖平衡、清晰留白 | 凭空加冰、改变鱼种或切片数、漂白原色 |
| 甜品、蛋糕 | 奶油形态、装饰坐标、层次、色泽 | 柔和空间、细腻材质、轻盈或雕塑式标题 | 奶油重塑、糖饰移位、增加水果、食物变玩具 |
| 饮品、咖啡、茶 | 杯型、液面、冰块/泡沫/拉花 | 透光感、背景虚实、竖向构图、品牌节奏 | 液面和杯标变化、捏造珍珠/果肉、冰块数量漂移 |
| 鲜果、生鲜、沙拉 | 新鲜度可见线索、颗粒/叶片/切面结构 | 自然光、清晰色彩、通透空间、轻快图形 | 编造产地与功效、补出被挡住的果实、错误蜡质表面 |

表格是创意候选方向，不是强制模板。品牌规范、当前参考照片与活动目标优先。

## 2. DNA 档案

食物与器皿作为完整主体建立锁定项，每项包括 `observation / evidence_region / confidence / source / lock_level`。

- 身份：食物/商品种类、部件关系，不能把相似菜品当同一菜品。
- 数量：完整可见个数；被遮挡的只记「不可确定」，不推断总份量。
- 几何：外轮廓、长宽比例、厚度、层数、卷曲、切口、排列方向。
- 表面：纹理、焦痕、裂口、颗粒、裹粉、芝麻分布、奶油/酱汁/泡沫/糖霜分布。
- 状态：生熟、融化/凝固、汤色和液面；对曝光偏色与食材本色分别标注。
- 装盘：主次食材相对坐标、重叠遮挡关系、堆叠高度、负空间。
- 配菜：种类、数量可知程度、位置；不能把绿色配菜识别成任意葱花再补画。
- 器皿：类型、轮廓、颜色、材质、口沿、纹样、把手与盘边空间。
- 摄影：视角、透视关系、受光方向、阴影接触关系。

证据标签为 `VISIBLE / INFERRED / MISSING`。事实锁只依赖可见证据和用户明确补充；推测项不能自动提升为已知。

## 3. 默认严格保护的含义

`STRICT_2D_LOCK` 允许整体等比缩放、在画布中平移、背景替换、留白扩展，以及不改变身份的曝光/色彩调整。默认不旋转、非等比拉伸、透视变形、重排食材、改变装盘或生成原图看不见的侧面。默认不裁掉完整器皿；品牌明确允许的局部 Hero 裁切可单独记录，但保留关键身份和结构证据。

这里承诺保护结构，不宣称全图像素不变：调色、缩放和边缘合成都可能改变像素。真正需要固定主体像素时另设像素保留要求，并取消主体调色或几何重采样。

「创意强度」只能影响背景、字排、空间与色彩表达；不能对应更高的食物变形强度。

## 4. Stage A：可复用商业主体

推荐默认实现：

1. 保留原件，规范方向与色彩，记录文件哈希。
2. 提取食物与器皿整体蒙版；透明杯、玻璃、细面条、蒸汽等困难边缘进入重点检查，必要时人工修正。
3. 做非生成式曝光、高光、白平衡与局部明暗调整；不能抹掉真实纹理、改变熟度和配料颜色。
4. 确定主体与未来背景的光线兼容范围。背景迁就主体已有方向，需要大改时说明代价。
5. 保存主体图、蒙版、接触阴影层与调整记录，生成便于对照的母版预览。
6. 对原图逐项检查 DNA；通过记录绑定主体图与蒙版哈希，成为本任务唯一可用母版。

受控参考编辑分支：只有用户允许生成式主体优化、并且供应商真实通过相应能力验收，才可让 Image2 编辑食物区域。引用主图并明确不可变项。每次候选都与原图比较，不能只与上一次候选比较，避免累积漂移。失败只修复已观察到的问题，最多两次定向重试，再转保护合成或人工处理；禁止默默放松锁定。

原照片光线已经适用时，Stage A 可以直接建立受保护母版并质检；阶段存在不等于必须调用一次生图。

## 5. Stage B：海报联合构图

先交付布局方案，再做图像。布局对象包括 `hero / headline / subtitle / slogan / proof_points / brand / contact / action / foreground / background`。

布局采用画布归一化坐标和层级，记录每个对象的边界、最小可读大小、避让区域、对齐锚点、允许裁切和遮挡规则。正文颜色要对照最终背景检查，不能在只有色板时认定可读。

三类空间可按项目选择：

- 摄影空间：主物清晰，远景细节减弱，近景少量虚化辅助，背景光向与主体一致。
- 舞台空间：以光区、台面、结构框景制造尺度和纵深，不让台面穿过盘底。
- 图形空间：用文字、几何、叠层、版面节奏形成图底关系，不强加真实景深。

严格保护默认由 Image2 生成环境图，随后合成通过的主体。可以向模型提供布局与主体参考，但不能把其重绘出来的食物自动取代母版；如果模型生成了额外主物、器皿或配菜，该背景需清理或重做，不能与受保护主体叠成双份食物。

完成后检验接触阴影、颜色、边缘、透视是否融为一个场景；保真通过但显得像生硬抠图的作品仍然不合格。

## 6. 文案与装饰食材

主标题和 Slogan 可以创作，但菜品、原料、工艺、价格、产地、营养功效、奖项与优惠条件必须来自当前项目事实。正式文案以采用后的精确字符为准。

「3–5 个卖点」是信息设计容量建议，资料不足时允许少于 3 个，或给非事实性修辞草稿供采用；不能生成虚假配方、认证与地址电话。文案按主规格的 CopySet 保存，非事实性修辞可在直接完成模式授权内由系统选定；事实承诺、价格条件或用户锁定文案的实质改变需要用户明确采用，已授权范围内的字距/换行无需确认。

背景装饰出现原料会暗示产品含有该原料，因此默认仅使用用户确认的实际食材；不确定时用抽象材质与图形。即使原料已确认，增加实物装饰仍要在创意方案中清楚表示它属于场景，不能改变盘中原有食物数量与配方。

不凭空增加蒸汽、爆汁、冰霜等物理状态；只有资料支持且与原图一致时使用，风格库不能覆盖这项约束。

## 7. 质检与修复

| 检查 | 方法与证据 | 失败后的处理 |
|---|---|---|
| 主体来源 | 图层引用、图像哈希、允许的缩放和调整记录 | 阻止使用未通过母版 |
| 结构 | 对齐后的轮廓、特征点与视觉比较；数量/遮挡人工复核 | 回退主体或修正遮罩，不以审美分抵消 |
| 表面 | 局部纹理、切口、酱汁、焦痕分布对比 | 回到原图检查，去掉过强修饰 |
| 器皿/装盘 | 轮廓与拓扑关系对照 | 换背景或布局，不能重画器皿适应版式 |
| 合成 | 边缘、光向、接触阴影、透视、色彩 | 仅修环境/合成参数 |
| 食欲/质感 | 原图与可接受参考并列，指出具体原因 | 调整光色与背景；不能靠增加食材改善 |
| 文字/品牌 | 文本源比对、字体缺字检测、画面读回、二维码解码 | 只修改排版或正确资产 |
| 多比例 | 每个尺寸重新执行上述相关检查 | 当前比例单独返工 |

机械指标需在保留样本和故意改坏的对照样本上校准，不能把 SSIM、某个视觉分数或模型一句“完全一致”单独当保真证明。模糊、遮挡导致无法确认时输出「需复核」，不虚构精确数量或相似度。

## 8. 假设案例：同一张面包图的两个方向

假设输入为一只面包与其原有盘子；没有实际样图，本例不描述其切口、馅料或品牌事实。

自主创意方向：以可见表皮和真实烤色为视觉主角，顺应原光线建立有明暗层次的烘焙空间，短标题围绕轮廓排布，证明性卖点放入较安静的信息区。具体字体和色彩在看见照片后再决定。

风格方向：若选择「光影剧场」且兼容性通过，保留完整面包和器皿，采用风格定义的聚光区域、深浅层次与标题比例；不把风格示例里的牛排、火焰或黑金色套到面包上。

两个方向共享同一个通过的主体版本，结果差异来自设计语法。这是后续真实验收要证明的行为。
