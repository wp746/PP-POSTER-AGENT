# 活动宣传 KV 生产手册

版本：0.1 设计稿 · 2026-09-05
范围：活动资料分析、活动分类、城市研究、主题与视觉方案、事实及身份校验。本文定义目标行为，不代表已有可运行的软件或已经完成 Image2 实测。

[主规格](../Product-Spec.md)定义总规则；本手册负责细化，不降低其事实、主体与验收要求。

## 1. 活动 KV 的工作目标

一张活动 KV 要让目标受众先识别“这是为谁、做什么、为什么值得参与”，再找到时间、地点和参与入口。视觉张力来自与活动有关的主题、尺度、视线和空间关系；地标、吉祥物、文字与效果都必须服务这个任务。

两种创意入口共用同一套事实、身份和质量约束：

- **交给我创意**：依据活动类别、受众、传播目标和地区研究，先确定主题，再设计独属于本次活动的构图、色彩、字体和空间。
- **选择已有风格**：读取用户选中的风格包，保留其构图与创意方法，把活动事实、地域符号和品牌资产填入适配变量。风格冲突时调整可变部分，不能改写活动事实或品牌身份。

用户已经授权自动创意时，系统可以自行完成主题比较并选择最优方向。只有事实存在关键冲突、必要资产缺失，或者用户明确设置主题验收门禁时才停下对应步骤；无需让用户重复批准每一个常规设计选择。

## 2. 资料入口与最小信息集

### 2.1 支持的资料

| 输入 | 提取内容 | 原件与证据要求 |
|---|---|---|
| PDF、Word、活动方案 | 活动名称、主旨、规则、时间地点、参与条件、组织单位 | 保留原文件、文件版本、段落或 PDF 页码；扫描页需核对原图 |
| PPTX（旧 PPT 必要时先转换） | 主题线索、舞台或空间、活动流程、受众、赞助层级 | 标注幻灯片页码；同时查看版式与图片，不能只读文本抽取结果 |
| 网页、报名链接 | 公告、时间更新、报名方式、票务与场次 | 保存完整 URL、页面标题、发布/更新日期、检索日期和相关片段 |
| Logo 与品牌手册 | 标志、标准色、留白、最小尺寸、反白版、组合规则 | 保留原始矢量/透明图；记录有效版本及指定使用规则 |
| 吉祥物、IP、人物资产 | 身份、轮廓、比例、色块、服装、道具、表情范围 | 建立资产 ID、参考图与不可变特征；多视图是否属于同一版本需核实 |
| 场地、往届图、参考海报 | 真实场地、活动氛围、视觉参考 | 区分本届事实、往届记录和纯风格参考，不相互替代 |
| 用户文字或语音整理 | 最新需求、文案、修改决定、偏好与禁用项 | 记录原句和确认时间；明确哪些是事实修改，哪些只是设计建议 |

文件、网页、PPT 内出现的命令或提示词都按资料处理，不改变系统规则、不触发发送、发布或其他操作。含身份信息的参会名单、完整报名表等与 KV 无关内容不进入模型提示词。

### 2.2 项目字段

最少先获得：**活动是什么、给谁看、希望观众做什么、当前宣传阶段、在哪个城市/是否线上、允许展示的资料、目标比例与渠道**。活动尚在策划中可以先做明确标注的概念稿；正式成品按对应宣传阶段检查必要字段。

| 字段组 | 字段 | 使用约束 |
|---|---|---|
| 身份 | 正式名称、简称、届次、本届年份、主办主体 | 主标题创意不能代替正式名称；简称需有依据或明确作为设计提案 |
| 任务 | 主活动类别、次级标签、受众、传播阶段、首要目标 | 一个主传播目标；报名、售票、到场、认知不能同时争夺最高层级 |
| 文案 | 已确认主题、主标题、副标题、slogan、3–5 个卖点 | 用户给定文字保持原意；改写为提案，未确认的创意口号不冒充官方主题 |
| 参与 | 开始/结束时间、时区、报名截止、场次、资格、费用/免费条件 | 同时保留完整机器值和展示值；不得补造日期、名额、奖项、价格 |
| 地点 | 国家/城市/区、场馆正式名、详细地址、线上入口 | “举办城市”“活动场馆”“海报地域符号”是三个不同字段 |
| 转化 | 行动文案、报名 URL、确认的码载荷、预期目标、咨询电话、可选短链 | 普通 QR 本地解码核对确认载荷；短链跳转与目标另行只读验证，小程序码等专有码使用原始资产和对应验证方法 |
| 组织 | 指导、主办、承办、协办、冠名、战略合作、赞助、媒体支持 | 角色分别存储；按主办方提供的次序、组合与级别排版 |
| 资产 | Logo、吉祥物、IP、嘉宾图、场馆图、品牌规则 | 关联源文件及版本；禁止根据名称自行虚构 Logo 或嘉宾身份 |
| 交付 | 渠道、比例、像素、印刷规格、语言、交付时间、版本数量 | 多比例须重排并独立验收，不把裁切当作完整适配 |
| 创意边界 | 创意模式、风格包 ID/版本、必须保留、禁用、地域权重 | 真实场地模式与概念场景模式明确分开 |

### 2.3 证据账本：每一项事实可回到来源

每条字段至少记录：

```yaml
field_id: event.starts_at
raw_value: "原文，不改写"
normalized_value: null
status: missing # provided / verified / inferred / conflicted / missing
sources:
  - source_id: brief_v3
    file_or_url: "项目内路径或完整 URL"
    version: "主办方版本标识；未知则填 unknown"
    location: "PDF 第 8 页 / PPT 第 12 页 / 标题+段落"
    published_at: null
    retrieved_at: "2026-09-05"
    evidence_excerpt: "与字段直接相关的原文片段"
decision:
  selected_source: null
  reason: null
  confirmed_by: null
  confirmed_at: null
```

- `provided`：用户或材料提供，已定位来源；无冲突且在本次发布范围内才可支撑正式文案。
- `verified`：已核对本届有效资料，且相关冲突已解决；OCR 对关键字符的猜测不算核实。
- `inferred`：基于资料的推断，例如可能的核心受众；不能当成公开承诺。
- `missing`：没有足够资料。预告海报允许未公布的地点按事实省略，不能自动填充。
- `conflicted`：多个有效候选互相冲突；最终可发布版本不得保留关键冲突。

创意标题、Slogan 与主题提案单独进入 CopySet，采用 `proposed / adopted / superseded` 状态，不伪装成已核实事实。非事实性文案可由用户采用或在直接完成模式的创意授权内由系统选定；正式名称、日期、价格、条件与锁定文案的实质改变仍需用户明确修正。

文件本身即使刚上传，也不代表它的内容比官网更新。来源选择依次考虑：**用户明确指定的本届有效版本 → 主办方正式变更 → 本届官方公告/正式手册 → 本届其他官方资料 → 用户提供但版本不明的稿件 → 第三方报道/往届资料**。这是调查优先顺序，不能用来掩盖不同官方来源的实质冲突。

冲突处理生成一条简短记录：“PPT 第 8 页为 10 月 1 日；报名页标注 10 月 2 日；两处均未声明替代关系；需确定活动日期。”只追问会改变结果的字段，并继续做受众分析、可用资产整理和不依赖该字段的主题草案。所有已确认字段形成版本快照；后续更改日期或 Logo 时，标记受影响成品为过期，不能保留旧稿的通过状态。

## 3. 常见活动分类

一个活动选一个主类别，允许附加最多两个次级标签，例如“体育赛事 + 城市文旅 + 亲子”。分类决定理解重点和设计抓手，不等于固定风格；音乐节不必永远霓虹，文化活动也不必永远水墨。

| 类别 | 主要受众与传播目标 | 必要核心输入 | 可用视觉抓手 | 避坑 |
|---|---|---|---|
| 01 体育赛事与大众运动 | 选手、观众、运动社群；报名/观赛 | 项目、级别、组别、赛制、日期、资格、路线/场馆、报名 | 动作轨迹、运动器材的结构、速度层次、团队阵列、赛道空间 | 将概念路线冒充真实路线；动作和器材不符运动规则；未证实的奖金/级别 |
| 02 电竞与数字竞技 | 玩家、战队、粉丝；报名/观看 | 游戏/项目、赛制、平台、资格、阵容、直播入口 | 战术结构、对抗关系、数字竞技空间、角色身份 | 所有赛事套蓝紫光效；虚构授权角色、队标或冠军背书 |
| 03 科创、设计与技能竞赛 | 学生、创作者、开发者、行业人才；征集作品 | 命题、参赛对象、作品要求、截止日、评审/奖项、提交入口 | 核心创作工具、构造/生成过程、模块协作、突破的瞬间 | 只画奖杯不讲赛什么；夸大奖项、就业或资助承诺 |
| 04 行业大会、论坛与学术交流 | 从业者、决策者、研究者；注册/认知 | 议题、论坛层级、议程、嘉宾身份、日期、场地、注册 | 观点汇聚、议题结构、知识网络、舞台空间、文字秩序 | 空泛星球握手；未确认嘉宾或机构被当成已出席 |
| 05 展会、博览会与产业对接 | 采购商、品牌、专业观众；参展/预约 | 行业范围、展区、展期、地点、主办、观众准入 | 行业实物、展陈序列、尺度对比、产业关联、信息索引 | 把展品示意当成确切参展产品；展馆和入口位置混淆 |
| 06 产品发布与品牌体验 | 消费者、媒体、渠道；关注/预约/体验 | 产品准确版本、核心能力、发布主题、场次、品牌资产 | 产品英雄、材质、揭幕动作、功能驱动的空间比喻 | 虚构规格和效果；改变产品外形；视觉比产品更抢眼 |
| 07 开业、店庆与商业促销 | 商圈居民、老客、潜客；到店/下单 | 门店、日期、优惠内容及条件、有效期、地址电话 | 商品组合、庆祝节奏、价格层级、空间开门/汇聚 | 装饰淹没优惠规则；省略限制条件造成不同含义 |
| 08 音乐节、演唱会与现场演出 | 乐迷、观演人群；购票/到场 | 阵容、演出类型、场次、场馆、票务、座位/区域规则 | 声音的节奏、舞台感、艺人形象、光与空间、字形节拍 | 未授权改造艺人形象；艺人姓名、时段、票价错配 |
| 09 艺术展、影展与文化展演 | 文化受众、游客、行业观众；参观/购票 | 策展主题、作品/片单、作者、展期、场馆、署名 | 作品语言、观看框架、材质/光影、策展叙事、留白 | 复制作品时改掉关键细节；不当裁切；策展主题被通用文化符号覆盖 |
| 10 文旅节庆、非遗与城市活动 | 本地居民、游客、文化爱好者；参与/到访 | 活动内容、地点关系、文化来源、日期、参与方式 | 地方工艺、民俗动作、街区肌理、场景路径、当代转译 | 跨地域/朝代随意拼接；把宗教场所当成通用游乐背景 |
| 11 市集、美食节与生活方式活动 | 城市青年、家庭、消费者；到场/体验 | 摊位类型、活动亮点、时间地点、门票/预约、品牌 | 品类原生材质、餐饮/手作主体、游逛空间、社交场景 | 食品品类与活动不符；虚构参展商；信息挤成杂乱菜单 |
| 12 校园、青年与社团活动 | 学生、校友、青年群体；报名/参与 | 组织、范围、年龄/学籍条件、流程、日期场地、入口 | 校园生活、行动与协作、年轻字形、真实社群语义 | 刻板青春配色；虚构学校背书；资格条件藏在小字 |
| 13 培训、工作坊与知识分享 | 学习者、从业者；报名/学习 | 课程主题、内容、讲者资历、对象、时间形式、费用 | 方法可视化、工具与作品、学习过程、清晰知识层级 | 虚构证书、收益或学习成效；标题只剩焦虑刺激 |
| 14 亲子、儿童与家庭体验 | 家长、儿童、家庭；预约/参与 | 适龄范围、陪同规则、活动内容、时间地点、预约 | 尺度亲和、探索动作、可触摸材质、角色互动 | 忽视年龄和陪同条件；过度刺激/危险动作；吉祥物身份漂移 |
| 15 公益、社区与公共倡议 | 居民、志愿者、相关社群；参与/支持 | 组织身份、行动目的、参与方式、服务对象、时间地点 | 真实行动、人与环境关系、温暖秩序、共同完成的动作 | 编造受助者故事和成效；只用悲情；不清楚观众能做什么 |
| 16 组织庆典、荣誉颁奖与纪念活动 | 员工、校友、伙伴、获奖者；认同/出席 | 纪念对象、组织、年份/届次、表彰对象、议程、日期地点 | 成果主体、时间结构、共同记忆、仪式感与名字层级 | 套通用黑金奖杯；编造获奖结果；年份/届次与组织层级错误 |

第 07 类主要服务商业转化，第 16 类主要服务组织认同与仪式传播；同一次店庆若同时包含促销与颁奖，拆成不同传播任务的 KV。招聘会、招商会、婚庆/私人派对等可按实际业务增加类别；增加类别时补齐同样的受众、目标、输入、视觉抓手和避坑字段。

分类结果必须附一句解释，例如：“主类为科创竞赛，因为首要任务是征集设计作品；城市文旅只是命题内容，不应让画面变成旅游海报。”

## 4. 从材料中提炼传播主题

### 4.1 先生成活动理解卡

用六个简短结论完成理解，不抄整份方案：

1. **一句话活动事实**：谁，在何处，以什么形式，提供什么活动。
2. **受众动机**：目标人群为什么在意，最关键的顾虑是什么。无法从资料确认的判断标为推断。
3. **传播任务**：本张 KV 是预热、招募、售票、倒计时、现场导流还是成果回顾。
4. **证据充分的价值**：最多三个最有说服力的理由，不编造“全国第一”“顶级阵容”等承诺。
5. **独特性**：活动内容、主办品牌或地点中哪一点能区别于同类活动。
6. **观众下一步**：一个主要行动；次要联系信息放在低层级。

### 4.2 主题生成：活动命题 × 受众动机 × 地域语义

主题不是漂亮口号。主题包包含以下字段：

```yaml
theme_id: theme_01
official_theme: null       # 有官方主题则原样保留
creative_proposition: "本张 KV 想表达的一个判断"
audience_reason: "受众为何有共鸣"
event_evidence: ["关联的资料字段 ID"]
city_symbol: null          # 无实质帮助时可为空
symbol_role: "主体 / 空间骨架 / 远景识别 / 材质线索 / 不使用"
visual_action: "主体正在完成的一个动作或结构变化"
hero: "唯一第一视觉主体"
headline_proposal: "创意标题提案"
three_second_takeaway: "受众三秒内应该看懂什么"
cta: "主要行动"
rejected_elements: ["无关联的装饰及原因"]
```

每次最多比较三个**概念真正不同**的方向，而非同一画面换颜色。用五项判断筛选：活动可辨识、受众动机、主题可视化、品牌一致性、渠道可读性。用户已有明确主题时不重新发明主题，只提出其视觉表达。自动创意默认选择理由最充分的一案进入设计；用户希望先看方向时，交付主题卡并等待其指定的验收。

## 5. 地点研究：先判断是否需要，再决定怎么使用

### 5.1 地域权重

- **核心叙事**：活动本身围绕地方文化、城市运动、城市命题展开，地区可参与主视觉结构。
- **背景识别**：地点只是举办地，用一个克制的远景/形态/材质线索即可。
- **不入画**：线下活动也允许只在地址文字中出现城市；如果地标会削弱产品或品牌，省略地标。
- **真实场地**：当用户要求呈现真实举办空间，必须以实际场地资料为准；不能把城市著名景点冒充会场。

### 5.2 研究步骤

1. 从事实账本读取城市、区、场馆、活动关键词，区分同名地点。
2. 每城先提出 5–8 个候选，覆盖建筑、地形、工艺、地方材料、历史结构、当代生活；不要只列地标。
3. 用当地政府/文旅、博物馆/遗产管理方、场馆/主办方等官方资料核实名称、位置、关键外观与使用语境；必要时用第二个独立官方来源解决矛盾。
4. 建立地区符号卡：名称、事实来源、参考外观、时代/文化语境、与本活动的连接、能执行的视觉动作、容易产生的误读。
5. 打分并写出取舍理由。通常仅用一个主地域符号；第二个只能承担必要辅助任务。
6. 进入构图后再次检查：去掉地区符号，活动是否仍然清楚；替换城市名称，画面是否仍然成立。前者回答活动主体是否够强，后者帮助识别是否只是通用模板。

不需要为了装饰而调查与任务无关的城市信息。搜索得到的图片可以用于分析外观；实际使用图片时记录素材来源和适用使用条件，不能把搜索缩略图直接当作已获授权的正式资产。

### 5.3 候选评分

评分是设计判断，不能包装成用户调研或客观实验结论。每项 1–5 分：

| 指标 | 1 分 | 3 分 | 5 分 |
|---|---|---|---|
| R 活动关联度 | 与活动无关 | 可以解释但需要文字辅助 | 直接表达活动内容或受众动机 |
| G 地域识别度 | 可属于很多地方 | 本地受众容易识别 | 目标受众有较强识别可能，且来源可核实 |
| N 叙事用途 | 纯装饰 | 支撑氛围或空间 | 能承担活动的关键动作、结构或比喻 |
| D 喧宾夺主风险 | 容易保持活动主体地位 | 需要控制比例/位置 | 极容易被看成旅游、历史或另一类活动 |

`候选分 = 20 × [0.35R + 0.25G + 0.25N + 0.15(6−D)]`

分数辅助排序，硬冲突直接淘汰：实际城市不符、关键外观未核实、与品牌规则冲突、会让观众误解真实地点/活动内容。若所有候选缺乏活动关联，采用无地标方案，不强行挑最高分。

### 5.4 西安示例：已核实事实与假设方案分开

以下仅为系统设计示例。**没有真实活动委托，未确认活动日期、路线、场馆、主办方、报名入口或任何宣传承诺。** 假设任务是“面向城市青年的跑步活动报名 KV，举办城市西安，以城市活力为传播主题”。

已核实的地区事实：

- **秦始皇陵及兵马俑**：UNESCO 将其与秦始皇陵、秦代军阵及写实雕塑联系起来；其遗产语义有明确的历史与陵墓背景。因此用于当代活动时，应判断军阵/守护/工艺结构是否与主题有关，而非默认把兵马俑当吉祥物。[UNESCO：Mausoleum of the First Qin Emperor](https://whc.unesco.org/en/list/441/)（检索：2026-09-05）
- **大雁塔**：西安市地方志办公室将其记为大慈恩寺内的七层塔，并说明其为玄奘藏经而建及古都西安象征的语境。若具象呈现，关键轮廓和层数需与有效参考匹配。[西安市地方志办公室：大雁塔](https://xadfz.xa.gov.cn/xadq/rwxa/1802954373708996609.html)（发布：2024-06-18；检索：2026-09-05）
- **西安城墙**：曲江新区管委会资料明确其现存城墙与明代城垣的关系，可作为城市空间和城垣结构的研究对象；不应在海报中称其为秦代城墙。[西安曲江新区管理委员会：西安城墙景区](https://qjxq.xa.gov.cn/zjqj/qyts/5df21c3a65cbd81235fc1bf1.html)（检索：2026-09-05）
- **长安与交流路径**：UNESCO 的“长安—天山廊道”介绍支持把长安与历史交流路径联系起来；将这层语义用于现代创意属于设计转译，不能宣称假设活动属于该遗产项目。[UNESCO：Silk Roads, the Routes Network of Chang'an-Tianshan Corridor](https://whc.unesco.org/en/list/1442/)（检索：2026-09-05）

针对上述**假设跑步任务**的主观候选评估：

| 候选 | R | G | N | D | 候选分 | 判断 |
|---|---:|---:|---:|---:|---:|---|
| 城墙轮廓与延展空间 | 4 | 5 | 4 | 2 | 85 | 适合用连续结构带动向前运动；只作城市识别，未核实前不能表现为真实赛道 |
| 长安交流路径的抽象线网 | 3 | 3 | 4 | 2 | 68 | 可表达连接与出发，但地域识别需要标题辅助 |
| 大雁塔剪影 | 2 | 5 | 2 | 3 | 58 | 识别直接，跑步关联弱；可作为小比例远景候选 |
| 兵马俑具象主体 | 2 | 5 | 3 | 5 | 57 | 容易把主视觉变成历史文旅；本假设任务不选择 |

选定概念示范：**“让古城的时间，跑出今天的节奏”**，这是创意主题提案，并非官方活动口号。

- 活动层：跑者与向前的动作占据第一视觉层，身体与运动姿态必须合理。
- 城市层：城墙轮廓位于远景，给出空间纵深和城市识别；不描画未经确认的比赛路线，不暗示城墙是实际活动场地。
- 主题层：近处运动的清晰动态与远处静稳的城垣形成关系，用景深和尺度表达时间与当下。
- 文字层：标题沿前进方向形成阅读节奏；正式活动名、时间、地点和报名入口由确定性排版写入。
- 删除：兵马俑、大雁塔、唐装人物、灯笼、烟花等没有独立叙事任务的叠加元素。

若任务换成“历史工艺主题的设计竞赛”，兵马俑的构造、工艺或阵列可能更有价值；若换成“国际文化交流论坛”，交流路径可能优于城墙。需重新评分，不能沿用跑步活动结论。

## 6. 品牌、Logo、吉祥物与 IP 身份锁

### 6.1 身份资产清单

每个资产记录原文件、版本、所属角色、是否必须出现、允许的表现形式及不可变项。品牌手册已经规定的内容直接执行；只有缺少且会影响使用的内容才追问。

| 资产 | 必须锁住 | 可变内容 | 默认处理 |
|---|---|---|---|
| Logo | 字形、图形轮廓、比例、字距、组合关系、指定色、组织归属 | 手册允许的尺寸、标准反白/单色版和位置 | 使用原始资产确定性合成；不让 Image2 重绘正式 Logo |
| 吉祥物/IP | 轮廓、头身比、五官位置、标志色块、服装、徽标、专属道具 | 已允许的表情、姿态、照明、背景 | 参考约束生成后逐项比对；严格版本可直接合成原件 |
| 嘉宾/艺人 | 本人身份、姓名职务、头像版本、阵容归属 | 允许的裁切、光影与背景 | 优先原照片合成；不凭名字生成“长得像”的替代人像 |
| 产品/场馆 | 产品版本、可辨形体、建筑关键结构和真实位置 | 授权的拍摄表现或明确概念化处理 | 真实呈现模式必须有相应参考 |

只有一张吉祥物参考时，不假定背面纹样、隐藏服装或道具细节。优先沿可见角度创作；确需新角度，先暴露哪些结构需要推断，再按用户已有授权处理。

### 6.2 组织与赞助层级

保持主办方给定的称谓、顺序和 Logo 锁定组合。例如“冠名赞助商”不能简化成“主办方”，“媒体支持”不能变为“联合主办”。同层级是否等大、按中文/英文/指定顺序、是否需要特殊位置由资料决定，不能让模型按美观自行重排组织关系。

没有明确层级时，可以完成可编辑的中性占位布局，但正式成品需要锁定组织字段和对应资产。占位稿应明确标识，不能作为已完成成品导出。

## 7. 把主题变成 Image2 可执行的视觉设计

### 7.1 视觉方向单

在生成前写出可检查的设计决定：

1. **单一主视觉**：活动主体是什么，为什么具有第一注意力。
2. **空间分层**：前景导向物、中景主体、远景环境分别承担什么工作；虚实和遮挡是否合理。
3. **动势与构图**：轴线、视线、尺度对比、主要留白区和信息区。
4. **品类色彩**：依据活动属性、品牌与情绪决定色彩，不预设蓝紫、黑金或大红为高级。
5. **字体角色**：标题字体表达活动性格，正文负责准确信息；明确中文与数字表现、字重、字距、行距和对比关系。
6. **信息层级**：主题/正式名、主要利益、时间地点、报名与组织信息的阅读顺序；3–5 个卖点可以分组，不能全部争夺主标题位置。
7. **区域保护**：Logo、二维码、长地址、电话及赞助组的安全区域，主体不得挤压或遮挡。
8. **多比例规则**：哪些主体可以移动/缩放，哪些文字可重新分行，哪些不能裁掉；宽屏与竖版的构图分别定义。

“世界级”作为创作目标，验收要落在可观察行为：主题清楚、主体强、字号层级明确、字形与活动气质相符、细节一致、空间有组织、信息可用。不能用一句“国际大师设计”代替设计决策。

### 7.2 生成与合成职责

Image2 负责活动主视觉、空间、光色、材质和需要生成的装饰性视觉。正式文案、Logo、二维码、电话和组织层级由可编辑的确定性合成层写入。艺术化标题可使用生成的材质裁入本地准确字形；正式字形由可用字体或确认的矢量字形控制并逐字核对。整张含字生成仅作可选概念探索，不能跳过主规格的文字与可编辑内容要求。

优先先产出主视觉并验证主题、身份和区域，再排版成 KV。任何图生图生成都保留本次输入资产与输出记录；只有本次已经验收的主视觉才能进入后续合成，不能误用上一个活动的图。

### 7.3 风格包调用

活动风格包至少提供：适用活动/受众、核心创意结构、主体组织方式、空间与虚实规则、文字语法、色彩/材质逻辑、资产约束接口、比例变体和失败特征。

调用顺序：`事实与身份锁 → 本次主题 → 风格适配检查 → 风格变量绑定 → 视觉方向单 → 生成与校验`。

例如选到“微缩舞台”风格，应学到“活动主体形成舞台叙事、观者从层次关系理解规模”的方法；不能把旧提示词中的上海、音乐节、红色钢琴直接带进西安跑步活动。学习获得的风格可先登记为待验证，经过适配案例与视觉验收后再成为可稳定使用的风格；一条提示词写入文件不等于风格已验证。

## 8. 验收与回修

### 8.1 硬性门槛

下列任一失败都不能交付为可发布成品：

- 时间、地址、报名截止、电话、费用条件、活动名称等关键事实错误或存在未解决冲突。
- 必需字段缺失，或用虚构文字填补缺失；预告阶段主动不公布的信息按阶段要求处理。
- 主办/承办/赞助层级与 Logo 对应错误，品牌/吉祥物/IP 身份漂移。
- 正式文案错字漏字、OCR 与源文案不一致且未完成原图复核。
- 普通二维码无法解码、载荷不匹配确认值，或码/信息被裁切遮挡；专有码未通过其适用验证方法，不假装普通 QR 解码器支持它。
- 把概念地标、虚构地点或创意路线当作真实活动场地/路线呈现。
- 任一请求比例尚未独立验收，或事实更新后仍引用旧版本通过记录。

URL 检查只在主规格限定的公开 HTTP(S) 抓取范围内验证跳转和目标页面，不代替用户填写报名、支付或发送信息，不自动唤起具有操作效果的外部入口。短链的载荷与最终地址分别保存；专有码按其已实现验证方法检查，未实现时需人工复核。访问限制时如实记录可达性未验证，不能把解码成功说成报名链路成功。

### 8.2 视觉验收评分建议

硬性门槛全部通过后，统一采用主规格的 1–5 级审美量表，初版建议各项均不低于 4 级。活动评审特别提供主题与活动匹配、主体和空间、文字层级、色彩与类别性格、品牌与地域融合、渠道适配的实际画面证据。平均分不能抵消短板。第 5.3 节地域候选分仅用于选题排序，不是成品验收分；这些都是待实际样本校准的内部标准，不是质量实测结论。

至少检查原尺寸、常用手机预览尺寸和缩略图：缩略图能识别活动主旨，手机能读主要时间地点与行动入口，原尺寸能核对小字与资产边缘。长赞助清单可以使用同一 KV 系列的延展版，不能靠无限缩小文字解决。

回修依据具体失败点：文案错字只修文字层；Logo 错误只修资产层；主体身份漂移重做主体；空间抢占信息区才调整构图。每次修改后只重验受影响项及最终完整性，不无理由反复生成整张海报。

## 9. 每次项目交付的最小证据包

1. `活动理解卡`：分类、受众、传播任务、创意模式、主题与选择理由。
2. `事实快照`：最终文案与必要字段、证据定位、版本及未采用的冲突记录。
3. `资产清单`：原 Logo/IP/人物/场地的版本与使用位置。
4. `地区研究卡`：仅保留实际影响设计的来源、日期、候选判断与选用理由。
5. `视觉方向单`：构图、光色、空间、字体、比例适配及风格包版本。
6. `成品与可编辑内容`：每个请求比例的 KV、图像层、正式文案/Logo/二维码的编辑数据。
7. `验收记录`：事实、身份、文字、二维码、视觉与各比例通过情况；未完成项明确标为待验证。
